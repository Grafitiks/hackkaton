## 1. Назначение решения

Программный комплекс решает обе ключевые задачи трека «Космохакатон» и предоставляет полнофункциональную геоинформационную платформу:

1. **Задача 1 (Реконструкция пропусков `primary_ndvi`):**
   - Восстановление целевого вегетационного индекса в условиях облачности, теней и сенсорных пропусков.
   - **Алгоритм:** 5-фолдовый ансамбль моделей градиентного бустинга **LightGBM Huber + CatBoost Huber** (веса $0.60 / 0.40$) на пространстве из 43 признаков (двунаправленные временные лаги, производные наклона вегетационной кривой, квадратичная межсенсорная гармонизация Landsat/MODIS $\leftrightarrow$ Sentinel-2, поправка Тейлора на кривизну фенологии, скользящие погодные окна ERA5).
   - **Результат:** $\text{RMSE} = 0.0716$, $\text{GapScore} = 8.52 / 30$ (прирост относительно базовой интерполяции в 13.5 раз).

2. **Задача 2 (Детекция и интерпретация аномалий вегетации):**
   - Выявление угнетения биомассы относительно многолетней климатической нормы DOY 2014–2026 ($\mu_{\text{doy}}, \sigma_{\text{doy}}$) по стандартизованной шкале Z-Score:
     $$Z = \frac{\text{NDVI} - \mu_{\text{doy}}}{\sigma_{\text{doy}}}$$
   - **Классификация состояний:**
     - $Z \ge -1.0$: *«Штатное развитие»*;
     - $-2.0 \le Z < -1.0$: *«Угнетение биомассы»*;
     - $Z < -2.0$: *«Критическая аномалия»*.
   - **Факторная диагностика причин:** сопоставление аномальных периодов с метеорологическим контекстом ERA5-Land (почвенно-атмосферная засуха по осадкам и ГТК Селянинова, экстремальный тепловой стресс $T > 30^\circ\text{C}$, дефицит тургора по индексу влагосодержания NDWI) и формирование предписаний агроному.

3. **Геоинформационный веб-сервис GEO-VEGA:**
   - Интерактивная карта (Esri Satellite, OpenStreetMap, CartoDB);
   - Режим свободного оконтуривания полей (Leaflet.Draw) с проверкой принадлежности к созданным группам;
   - Автоматический поиск полей через Overpass API (`landuse=farmland`);
   - Полнофункциональный расчет зональной статистики Google Earth Engine (GEE);
   - Аналитические дашборды динамики вегетации (Chart.js) и экспорт верифицированного агрономического паспорта поля с оттиском печати.

## 4. Источники и структура данных

### Структура входных данных соревнования:
1. **`data/train_dataset.csv`** (99 955 строк, 39 полигонов, период 2010–2025 гг.):
   - `anon_polygon_id`: зашифрованный идентификатор поля;
   - `date`: дата наблюдения в формате `YYYY-MM-DD`;
   - `crop_type`: сельскохозяйственная культура (озимая пшеница, подсолнечник, ячмень, кукуруза, рапс и др.);
   - `primary_ndvi`: целевой вегетационный индекс (Sentinel-2, при отсутствии — Landsat, при отсутствии — MODIS);
   - `s2_ndvi`, `landsat_ndvi`, `modis_ndvi`: сырые индексы соответствующих спутниковых сенсоров;
   - `s2_ndwi`, `landsat_ndwi`: спектральные индексы увлажненности растительности (NDWI);
   - `s2_evi`, `landsat_evi`: модифицированные вегетационные индексы (EVI);
   - `era5_temp_c`, `era5_precip_mm`: метеорологические параметры реанализа ERA5-Land (температура и осадки).

2. **`data/test_features (1).csv` / `data/private_features.csv`** (57 185 строк, 78 полигонов):
   - Содержит все те же колонки, а также бинарный флаг `is_synthetic_gap = True` для ровно **3 112 скрытых контрольных точек**, подлежащих восстановлению.

### Дополнительные внешние источники:
- **Google Earth Engine (GEE):** `COPERNICUS/S2_SR_HARMONIZED` (разрешение 10м, спектральные каналы B2, B3, B4, B8, B11, B12, маскирование облачности и теней по слою SCL/QA60).
- **ECMWF ERA5 & ERA5-Land Reanalysis (Open-Meteo Global Historical Weather API):** среднесуточная температура, суточные осадки, гидротермический коэффициент Селянинова (ГТК), суммы активных температур.
- **OpenStreetMap Overpass API:** векторная картография границ реальных сельскохозяйственных контуров (`landuse=farmland`, `boundary=administrative`).
- **AWS Earth Search STAC:** оперативные метаданные спутниковых съемок Sentinel-2 L2A.

## 5. Команды сбора и предобработки данных

Скрипты предобработки и сбора данных инкапсулированы в модулях `src/` и не требуют ручных манипуляций:

1. **Генерация 43 признаков и гармонизация сенсоров:**
   Реализована в [src/features/feature_builder.py](src/features/feature_builder.py):
   - Приведение Landsat и MODIS в эталонное пространство Sentinel-2 квадратичными полиномами:
     $$\text{NDVI}_{S2} = a \cdot \text{NDVI}^2 + b \cdot \text{NDVI} + c$$
   - Двунаправленный поиск предшествующих ($p_1, p_2$) и последующих ($n_1, n_2$) безоблачных наблюдений;
   - Расчет локальных производных $\text{slope}_p, \text{slope}_n$ и кривизны Тейлора $\frac{1}{2} \Delta t_{p1} \Delta t_{n1} \cdot \text{clim\_slope}$;
   - Агрометеорологические скользящие окна ERA5 (суммы осадков за 7 и 14 дней, температура за 7 дней).

2. **Расчет многолетней климатологии DOY:**
   Реализован в [src/features/climatology.py](src/features/climatology.py):
   - Расчет сглаженной климатической нормы $\mu_{\text{doy}}, \sigma_{\text{doy}}$ по полигонам, культурам и глобально за период с 2014 по 2026 год.

3. **Онлайн-запрос свежих данных спутников и погоды:**
   - Проверка и настройка подключения Google Earth Engine:
     ```bash
     python setup_gee.py
     ```
   - Запросы к ERA5 и Overpass API выполняются автоматически сервисом в реальном времени при выборе любого поля или рисовании контура на карте.

## 6. Обучение моделей и артефакты

### Готовые артефакты «из коробки»:
В директории `artifacts/models/` уже находятся полностью обученные и верифицированные артефакты, готовые к инференсу без необходимости повторного обучения:
- **`artifacts/models/ensemble_models.pkl`** (17.5 МБ):
  - 5 обученных моделей LightGBM Regressor (Huber Loss);
  - 5 обученных моделей CatBoost Regressor (Huber Loss);
  - Оптимальные веса блендинга: LightGBM = 0.60, CatBoost = 0.40;
  - Спецификация 43 признаков и калибровочные статистики по датам и культурам.
- **`artifacts/models/climatology.pkl`** (433 КБ):
  - Таблицы климатической нормы DOY по 78 полигонам и культурам.

### Команда переобучения моделей с нуля:
Для полного воспроизведения обучения и обновления артефактов запустите:
```bash
python train.py
```
Скрипт автоматически:
1. Загружает обучающий датасет `data/train_dataset.csv` и тестовый датасет;
2. Рассчитывает и сериализует климатологические профили DOY в `climatology.pkl`;
3. Проводит Group-K-Fold (5 фолдов по `anon_polygon_id` для предотвращения утечки данных между полями);
4. Обучает модели LightGBM и CatBoost, оптимизирует веса блендинга и сохраняет `ensemble_models.pkl`.

Дополнительные аргументы:
```bash
python train.py --train-path data/train_dataset.csv --test-path "data/test_features (1).csv" --output-dir artifacts/models
```

## 7. Команда инференса и submission.csv

Для генерации файла предсказаний на тестовых данных запустите команду инференса:

```bash
python predict.py
```
или с явным указанием путей через:
```bash
python predict_submission.py --input "data/test_features (1).csv" --output submission.csv
```

### Место появления и формат `submission.csv`:
- Итоговый файл сохраняется непосредственно в корне репозитория: **`./submission.csv`**.
- **Проверка формата по регламенту соревнования:**
  - Количество строк: ровно **3 112 строк** (соответствует точкам `is_synthetic_gap = True`);
  - Колонки: `date`, `primary_ndvi_true`, `anon_polygon_id`;
  - Отсутствие пропусков (NaN): **0**;
  - Отсутствие дубликатов по паре `(anon_polygon_id, date)`: **0**;
  - Значения индекса строго ограничены физическим диапазоном $[0.08, 0.95]$.

## 8. Детекция аномалий и веб-интерфейс

### 1. Консольный запуск детекции аномалий (CLI)
Для запуска модуля детекции аномалий (Задача 2) из терминала выполните:
```bash
python detect_anomalies.py
```
Дополнительные параметры:
```bash
# Анализ конкретного полигона с сохранением подробного отчета:
python detect_anomalies.py --input data/train_dataset.csv --polygon-id AOI-0002 --output anomalies_report.json
```
Скрипт выводит:
- Распределение статусов (*«Штатное развитие»*, *«Угнетение биомассы»*, *«Критическая аномалия»*);
- Реестр непрерывных стрессовых интервалов;
- Агрометеорологические первопричины (засуха по осадкам, температурный шок по ERA5, потеря тургора по NDWI);
- Сохраняет структурированный JSON-отчет с агротехническими рекомендациями.

### 2. Запуск демонстрационного геоинформационного веб-интерфейса
Для запуска интерактивного веб-сервиса выполните:
```bash
python run_server.py
```
И откройте в браузере:
- **Веб-дашборд:** [http://localhost:8000](http://localhost:8000)
- **Интерактивная спецификация REST API (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)

#### Ключевые возможности веб-интерфейса:
1. **Интерактивная карта агромониторинга:**
   - Подложки: Esri World Imagery (высокодетальный спутник), OpenStreetMap, CartoDB Dark Matter.
   - Организация полей по папкам и группам (хозяйства, севообороты, кластеры) с возможностью переименования и удаления.
   - Свободное оконтуривание полей кнопкой **«Нарисовать контур»** (Leaflet.Draw) с предварительной валидацией выбора папки.
   - Интеллектуальный поиск контуров полей через Overpass API с независимым анализом при клике левой кнопкой мыши и добавлением в группу только по желанию пользователя с обязательным вводом наименования поля.
2. **Аналитический дашборд вегетации и метеорологии:**
   - График хода вегетации (NDVI): фактические точки Sentinel-2 (10м), Landsat 8/9 (30м), MODIS (250м), плавная линия реконструкции 5-Fold ML и коридор многолетней климатической нормы $\pm 1\sigma$.
   - Синхронный график метеорологии ERA5 (суточная температура, осадки).
   - Инструменты масштабирования (зум, панорамирование, сброс масштаба).
3. **Панель источников данных и алгоритмов:**
   - Отображение актуальных провайдеров (GEE & STAC Sentinel-2 10м, Landsat, MODIS, ECMWF ERA5, ансамбль 5-Fold LightGBM + CatBoost на 43 признаках, климатология DOY).
4. **Агрономический паспорт поля:**
   - Генерация официального цифрового документа с реестром аномалий, факторами риска, директивами агроному и оттиском печати системы GEO-VEGA с поддержкой печати на принтере / сохранения в PDF.
5. **Экспорт данных:**
   - Выгрузка суточного ряда вегетации и погоды в **CSV** и геопривязанного паспорта поля в **GeoJSON**.
