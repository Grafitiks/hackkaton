# GEO-VEGA // Космохакатон: Мониторинг вегетационной динамики с/х территорий

Комплексный программный комплекс для мониторинга вегетационной динамики сельскохозяйственных угодий по данным ДЗЗ (Sentinel-2, Landsat, MODIS) и реанализа ERA5:
1. **Задача 1:** Высокоточное восстановление пропущенных наблюдений вегетационных индексов (`primary_ndvi`) с помощью 5-фолдового ансамбля **LightGBM + CatBoost** (метрика **GapScore**).
2. **Задача 2:** Автоматическая детекция и агрономическая интерпретация аномалий вегетации на основе Z-score отклонений от климатической нормы и метеоконтекста (засухи, тепловой стресс).
3. **Веб-интерфейс:** Интерактивное геоинформационное веб-приложение с картой (Esri Satellite), выбором готовых полей или свободным рисованием произвольного контура и аналитическим дашбордом.
4. **Автономный сбор актуальных и ретроспективных данных (Online API):**
   - **Google Earth Engine (GEE - АКТИВЕН):** Прямой расчет зональной статистики и безоблачных мультиспектральных наблюдений Sentinel-2 (`COPERNICUS/S2_SR_HARMONIZED`) для произвольного контура по проекту `ee-agro-hackathon`.
   - **Open-Meteo ERA5 Reanalysis API:** Прямой сбор реальных суточных метеоданных (температура, осадки) для любых географических координат Земли за любой год (2010–2025+).
   - **OpenStreetMap / Overpass API:** Динамический поиск и загрузка реальных контуров полей (`landuse=farmland`) по кнопке на карте.
   - **Earth Search AWS STAC API:** Запрос реальных пролетов спутника Sentinel-2 L2A и маски облачности.
5. **Batch-инференс:** Консольная утилита для формирования строго валидного `submission.csv`.

## 🐳 Воспроизводимый запуск через Docker (Рекомендуется для жюри)

Проект полностью контейнеризирован и запускается **одной командой** без необходимости предварительной настройки Python и библиотек:

```bash
docker compose up --build
```

После старта контейнера откройте в любом браузере:
- **Интерактивный веб-дашборд мониторинга:** [http://localhost:8000](http://localhost:8000)
- **Интерактивная спецификация REST API (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)

Остановка контейнера:
```bash
docker compose down
```

## 🚀 Локальный запуск (без Docker)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск Batch-инференса (Задача 1 $\rightarrow$ `submission.csv`)
Для формирования файла предсказаний на основе тестовых данных выполните:
```bash
python predict_submission.py --input data/private_features.csv --output submission.csv
```
Скрипт автоматически:
- Загружает предобученный ансамбль моделей и таблицы климатологии;
- Извлекает bi-directional признаки для 3 112 строк с `is_synthetic_gap = True`;
- Формирует файл `submission.csv` со столбцами: `anon_polygon_id,date,primary_ndvi_pred`.

### 3. Запуск веб-сервиса (Интерактивная карта и дашборд)
Для запуска локального сервера выполните:
```bash
python run_server.py
```
После запуска откройте в браузере:
- **Веб-интерфейс:** [http://localhost:8000](http://localhost:8000)
- **Интерактивная документация API (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)

## 🌟 Возможности веб-интерфейса

- **Интерактивная спутниковая карта (Esri World Imagery + OSM):**
  - Просмотр каталога реальных сельскохозяйственных полей Самарской области.
  - **Свободное рисование контура поля:** инструмент Leaflet.Draw позволяет выделить произвольный участок на карте и мгновенно получить прогноз вегетации и анализ рисков.
- **Двухсегментный аналитический дашборд:**
  - **График NDVI:** отображение сырых точек спутников (Sentinel-2, Landsat, MODIS), восстановленной плавной кривой ML и коридора климатической нормы ($\pm 1\sigma$).
  - **График погоды:** суточная температура и осадки ERA5 Reanalysis.
- **Журнал аномалий и экспертные рекомендации:**
  - Автоматическая группировка дней угнетения биомассы ($Z < -1.0$) и критических аномалий ($Z < -2.0$).
  - Анализ причин: почвенно-атмосферные засухи, термический шок ($T > 30^\circ C$), дефицит влаги в фазу цветения.
  - Практические рекомендации агроному (некорневые подкормки, контроль влагозапасов, полив).
- **Встроенная панель Batch-инференса:**
  - Просмотр характеристик итогового сабмита и прямое скачивание `submission.csv` из браузера.

## 🔬 Воспроизведение обучения моделей

Для повторного запуска полного цикла кросс-валидации и обучения ансамбля с нуля:
```bash
python src/models/train.py
```
Скрипт обучит 5-фолдовый ансамбль LightGBM + CatBoost и обновит артефакты в `artifacts/models/`.
Локальный результат валидации: **RMSE 0.0716 | GapScore 8.52 / 30** (прирост в 13.5 раз относительно baseline).
